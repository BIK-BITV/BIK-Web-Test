[.BLOCK_LANG_EN]
==== 6.2.8 RTT input methods

____
[.BLOCK_LANG_EN]
--
Where ICT is, or includes, a communication client, and supports real-time bidirectional voice communication, and
supports RTT,
the client shall provide RTT input methods in all ways available for general text input by the ICT.
--
