== Wie wird das geprüft?

Alle Eingabemöglichkeiten ausprobieren: Es wird jede auf dem Gerät verfügbare Option zur Texterstellung getestet
(z. B. physische Tastatur oder Bildschirmtastatur, Spracheingabe, alternative Tastaturen, über Anschlüsse
wie Wi-Fi®, Bluetooth® usw. angeschlossene Tastaturen).
3. Überprüfen Sie, ob bei jeder Art der Zeicheneingabe Text in die RTT-Funktion
eingegeben und an das andere Endgerät gesendet wird.

[.BLOCK_LANG_EN]
==== 6.2.8 RTT input methods

____
[.BLOCK_LANG_EN]
--
Where ICT is, or includes, a communication client, and supports real-time bidirectional voice communication, and
supports RTT,
the client shall provide RTT input methods in all ways available for general text input by the ICT.
--
